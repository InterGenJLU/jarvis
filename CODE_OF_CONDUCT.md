# Code of Conduct

## The Short Version

Be respectful. Be constructive. Help make JARVIS better.

This project pushes the boundaries of what's possible with local AI on consumer hardware. We welcome contributions, bug reports, and discussions from anyone — regardless of experience level, hardware, or background.

## Standards

**Encouraged:**
- Technical discussion grounded in data and testing
- Constructive criticism with actionable suggestions
- Sharing hardware benchmarks, test results, and configurations
- Helping others troubleshoot ROCm, VRAM, and model issues

**Not tolerated:**
- Harassment, trolling, or personal attacks
- Publishing others' private information
- Discriminatory language or behavior
- Spamming or self-promotion unrelated to the project

## Enforcement

Unacceptable behavior can be reported to the project maintainer via [InterGen Studios](https://intergenstudios.com). Reports will be reviewed promptly and handled confidentially.
